# Data Directory

This directory stores runtime data files for the DAISY voice assistant:

- `recording.wav` - Temporary audio recordings
- `transcription.txt` - Text transcriptions of speech
- `chat_history.json` - History of conversations
- `outputs/` - Generated audio files and other outputs

These files are excluded from version control via .gitignore.
